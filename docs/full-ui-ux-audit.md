# مراجعة UI/UX الشاملة — مرج

**التاريخ:** 25 أغسطس 2026  
**النطاق:** واجهة العميل ولوحة الإدارة، RTL، desktop وmobile، مع الاقتصار على البيانات والوظائف المتاحة فعليًا.

## Design brief المختصر

| البند | القرار الحالي |
|---|---|
| المنتج | متجر ملابس عربي مستقل باسم مرج، مع Virtual Try-On ولوحة تشغيل للمالك |
| الجمهور | متسوق يختار المنتج/المقاس ثم يطلبه، ومالك يدير الكتالوج والطلبات والإعدادات |
| المهمة الأهم | جعل قرار اختيار المنتج والطلب واضحًا، ثم جعل تنفيذ الطلب وإدارة المخزون سريعَين |
| الهوية | Arabic-first editorial catalogue: خلفية دافئة، حبر بحري، teal للإشارات الأساسية، عناوين عربية كبيرة |
| القيود | RTL، mobile-first، لا بوابة دفع أو تحليلات أو تتبع شحن موصولين، وعدم اختلاق حقائق تشغيلية |

| المنطقة | الدليل المرئي | الأثر | الأولوية |

## خطة التحقق

بعد تطبيق إصلاحات P1، يُعاد فحص desktop و390px و768px للطلبات ومحرر المنتج، مع keyboard focus وحالات empty/loading/error. ثم يمر `pnpm check` وVitest قبل النشر.

## الإصلاحات المنفذة ونتائجها

تم تحويل جدول الطلبات على الهاتف إلى بطاقات ذات labels صريحة للطلب والعميل والتوصيل والإجمالي والحالة والتاريخ، مع الإبقاء على table الكامل في desktop. كما تحولت صفوف variations في محرر المنتج إلى تخطيط card يربط كل قيمة باسمها، ويمنع scroll أفقيًا غير مفسّر في هذه المنطقة. تم ضبط البريد وأرقام التواصل لاتجاه LTR ومنع انقسامها إلى سطور قصيرة في بطاقات RTL.

المراجعة المرئية اللاحقة على 390px أظهرت بطاقات طلبات قابلة للمسح، ونص بريد كامل في سطر واحد، ومحرر منتج ذي تسلسل واضح من النشر والأسعار إلى البيانات والصور والـ variations. لم يغيّر CSS الجديد عرض desktop، حيث تبقى الجداول والنماذج ذات الأعمدة الكاملة.
