# دليل تشغيل ونشر متجر مرج (Laravel 11) على هوستنجر 🌊🚀

تم تحويل متجر **مرج (Marj)** بالكامل إلى بنية **PHP Laravel 11** الحديثة ليعمل بشكل أصيل وفائق السرعة على خوادم **Hostinger (Apache / OpenLiteSpeed)** بدون الحاجة لأي Node.js Runtime في الإنتاج.

---

## 🛠️ خطوات التشغيل على هوستنجر (3 خطوات فقط):

### 1️⃣ الدخول لمجلد الموقع وسحب المشروع عبر SSH:
```bash
cd ~/domains/maraj.pixelmindeg.com/public_html
git pull
```

### 2️⃣ تثبيت حزم Composer وتوليد المفتاح:
```bash
# تثبيت الحزم
composer install --no-dev --optimize-autoloader

# توليد مفتاح التطبيق
php artisan key:generate
```

### 3️⃣ ضبط الاتصال بقاعدة البيانات وتنفيذ المايجريشن والـ Seed:
في ملف `.env`:
```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=u708961508_marj
DB_USERNAME=u708961508_marjuser
DB_PASSWORD=YOUR_DB_PASSWORD
```

ثم نفّذ أمر المايجريشن والبيانات الافتراضية:
```bash
php artisan migrate:fresh --seed --force
```
