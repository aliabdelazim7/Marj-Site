# Arabic / English Localization and Direction Audit — مرج

## نموذج التشغيل

توجد طبقة لغة عالمية محفوظة في المتصفح وتعمل عبر مفتاح لغة في الهيدر ومفتاح موازٍ داخل لوحة الإدارة. العربية تضبط `lang="ar"` و`dir="rtl"`، والإنجليزية تضبط `lang="en"` و`dir="ltr"`. يمكن استخدام `?lang=ar` أو `?lang=en` لمعاينة كل نسخة بصورة حتمية أثناء QA؛ اختيار المستخدم في الواجهة يبقى محفوظًا.

| المنطقة | العربية / RTL | English / LTR | النتيجة |
|---|---|---|---|
| التنقل والهيدر | ترتيب أيقونات الحساب/المفضلة/السلة وقائمة الهاتف عربي ومنطقي. | يقلب اتجاه layout مع بقاء أيقونات السلة والقلب مفهومة بصريًا. | مكتمل |
| المتجر والكتالوج وPDP | العناوين والفلاتر والسعر والنصوص العربية تعرض RTL. | عناوين التنقل والكتالوج والمنتجات الأساسية والسعر تظهر بالإنجليزية وEGP. | مكتمل لواجهة النظام والمنتجات المزروعة |
| السلة وcheckout | أسعار وempty states وعناصر النموذج تتبع RTL. | التسميات الأساسية وCTA تتبع LTR؛ لا يتم إنشاء طلبات اختبارية. | مكتمل بصريًا |
| الإدارة | القوائم والبطاقات والجداول تعمل RTL على الهاتف وdesktop. | الحاوية والجداول تتحول LTR، ومفتاح اللغة يبقى متاحًا. | مكتمل بصريًا |
| القيم المختلطة | البريد والهاتف وSKU تظل LTR داخل العربية، والأسعار تتبع اللغة. | القيم اللاتينية تبقى سليمة في LTR. | مكتمل |

## حدود المحتوى الصادقة

النصوص التشغيلية وواجهات النظام، وبيانات الكتالوج الافتراضية الأربع، لها ترجمة إنجليزية في الطبقة الحالية. أمّا أوصاف منتجات جديدة أو ملاحظات شحن أو سياسات وإرشادات دفع يدخلها المالك لاحقًا بالعربية، فتبقى كما أدخلها المالك إلى أن يضيف نسختها الإنجليزية؛ لا تُترجم هذه البيانات تلقائيًا لأن الترجمة الآلية قد تغيّر حقائق المنتج أو الشروط التشغيلية.

## التحقق

تمت مراجعة `/`, `/products`, PDP, `/cart`, `/checkout`, `/admin`, `/admin/products`, و`/admin/orders` عند 1280px بالإنجليزية و390px بالعربية والإنجليزية. لم يظهر overflow مرئي بسبب تغيّر الاتجاه، وتبدلت الحاويات والجداول وقائمة الهاتف بصورة سليمة. اختبارات TypeScript وVitest تُشغَّل قبل النشر، بما فيها اختبار محدد للترجمة المشتركة واتجاه المستند.
