# مواصفات التشغيل: الشحن والدفع والتحليلات — مرج

## الغرض

> تجيب تبويبات التشغيل الجديدة عن ثلاثة أسئلة للمالك: ما رسم الشحن للمحافظة؟ ما طرق الدفع التي يمكن للعميل اختيارها الآن؟ وما الذي تقوله الطلبات والكتالوج المسجلان فعليًا؟

## مصادر الحقيقة

| المجال | المصدر | ما لا يمكن استنتاجه منه |
|---|---|---|
| الشحن | `shippingZones` ورسومه/حالة التفعيل من الإدارة | ETA أو تتبع شركة شحن ما لم يضفه المالك أو يربط مزودًا |
| الدفع | `paymentMethods`، مع `enabled` وتعليمات يحررها المالك | تأكيد تحصيل أو عملية بطاقة/محفظة ناجحة من دون مزود دفع |
| الطلب | `orders` و`orderItems`، مع استبعاد الطلبات الملغاة من قيمة الطلبات المسجلة | الإيراد المحصل، refunds، أو هامش الربح |
| الكتالوج | المنتجات والـ variations والمخزون الحالي | funnel/traffic/conversion من دون Analytics events |

## قواعد التشغيل

| القاعدة | التنفيذ |
|---|---|
| المحافظات | تهيئة 27 محافظة مصرية كـ zones قابلة للتحرير؛ مرجع نطاق القائمة هو صفحة محافظات رئاسة الجمهورية المصرية: [Governorates](https://www.presidency.eg/en/%D9%85%D8%B5%D8%B1/%D8%AE%D8%B1%D9%8A%D8%B7%D8%A9-%D8%A7%D9%84%D9%85%D8%AD%D8%A7%D9%81%D8%B8%D8%A7%D8%AA/). |
| رسم الشحن | الخادم يقرأ zone المحافظة المفعلة ويحسب الرسم؛ حد الشحن المجاني العام يظل أولوية عندما يتحقق. |
| الدفع النقدي | مفعّل كبداية ويظهر للعميل كدفع عند الاستلام. |
| المحافظ/التحويل | Vodafone Cash وInstaPay والتحويل اليدوي قابلة للتفعيل فقط عند إدخال تعليمات التحويل الفعلية من المالك. |
| البطاقات | تبقى «غير متصلة» حتى يختار المالك مزود دفع ويقدم بيانات تاجر/مفاتيح Test Mode؛ لا تحفظ أي أسرار في browser. |
| التحليلات | تعرض قيمة الطلبات المسجلة غير الملغاة، متوسط قيمة الطلب المسجل، رسوم الشحن المسجلة، الحالات، المحافظات، المنتجات، والمخزون. أي funnel أو إيراد محصل يعرض Blocked مع سبب واضح. |

## أسئلة مفتوحة للربط الحقيقي للبطاقات

لا يمكن ربط Visa أو بوابة محفظة online من دون اختيار مزود دفع وتوفير حساب تاجر وبيانات Test Mode. عند الاختيار، نحتاج اسم المزود، مفاتيح test/server-side فقط، عنوان callback/webhook إن لزم، وسياسة التعامل مع نجاح/فشل/إلغاء العملية. لا تفعّل الواجهة البطاقات قبل تحقق callback من الخادم.
