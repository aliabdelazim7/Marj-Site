# متطلبات تشغيل HoodieFit قبل الإنتاج

النسخة الحالية تعمل كمتجر محلي مستقل، وتستخدم **Cash on Delivery** مع قاعدة شحن ثابتة: 60 ج.م للطلبات الأقل من 2000 ج.م، ومجاني فوق ذلك. شاشة التأكيد لا تدّعي نجاح الدفع؛ الطلب ينتقل إلى حالة `pending` ويحتاج تأكيدًا هاتفيًا.

قبل تفعيل الدفع الإلكتروني، يجب اختيار مزود دفع يعمل في مصر، إضافة server-side webhook للتحقق من العملية، تخزين transaction reference وحالة الدفع منفصلة عن حالة الشحن، ومنع الاعتماد على نتيجة redirect القادمة من المتصفح وحدها. يجب أيضًا تفعيل HTTPS، التحقق من توقيع webhook، ووضع سياسة واضحة للتعامل مع فشل الدفع والإلغاء والاسترداد.

قبل إطلاق الشحن، يجب تعريف المحافظات والمناطق وأسعارها، ووقت التسليم المتوقع، وحدود الوزن، وآلية إعادة المحاولة، وخطوات الإرجاع والاستبدال. يفضّل تحويل قاعدة الشحن الحالية إلى جدول إعدادات أو قواعد shipping zones قابلة للإدارة بدل تعديل الكود.

الكتالوج المحلي الحالي يستخدم بيانات العرض الموجودة في `shared/products.ts`. جداول `catalogProducts` و`productVariants` جاهزة لاستقبال مخزون فعلي، لكن يجب إدخال صور verified inventory، SKU، stock لكل مقاس، وسياسة نفاد المخزون قبل ربطها بالكتالوج العام.
