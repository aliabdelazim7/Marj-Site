# Mobile Navigation and Responsive Audit — مرج

## قرار التنقل

أضيف شريط سفلي لواجهات العميل فقط، بخمس وجهات يمكن الوصول إليها بالإبهام: الرئيسية، المنتجات، التجربة الافتراضية، السلة، والحساب. لا يظهر في مسارات `/admin` لأن للوحة تنقل تشغيل مستقل، ولا يظهر في `/checkout` حتى لا ينافس إجراء الإتمام أو يغطيه.

## تحقق أولي

راجعت الصفحة الرئيسية والكتالوج وصفحة المنتج والمفضلة والسلة والإتمام والحساب ولوحة الإدارة على 390px بالعربية، ثم الواجهات الأساسية بالإنجليزية LTR. أُضيفت مساحة safe-area أسفل محتوى العميل، وتظهر صفحة الإتمام من دون navigation ثابت. لقطات الصفحة الكاملة تخفي العناصر الثابتة بطبيعتها؛ لذا يلزم فحص viewport مباشر للشريط السفلي قبل الإغلاق.

## تحقق viewport النهائي

في لقطة viewport مباشرة على 390px ظهر الشريط السفلي بوضوح بالعربية والإنجليزية: تبويب نشط بلون teal فاتح، زر تجربة افتراضية مميز، عداد السلة عند وجود عناصر، وأهداف لمس بحجم ثابت. ظهر الشريط في الرئيسية والسلة، واختفى في checkout وداخل الإدارة كما صمم. يحجز `body.has-mobile-bottom-nav` مساحة safe-area فقط عندما يظهر الشريط، لذلك لا يوجد فراغ إضافي في صفحة الإتمام أو الإدارة. كما صُححت جملة السلة الفارغة المختلطة في English بعد الفحص.

## حدود النطاق

لا يُضاف شريط سفلي للإدارة كي لا يكرر قائمة المشرف أو يحجب أدوات تحرير المنتج والطلبات. لم تُنشأ عناصر سلة أو طلبات اختبارية؛ عداد السلة يظهر إن وُجدت عناصر محفوظة في جهاز العميل.
